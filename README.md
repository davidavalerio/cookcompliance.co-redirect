# cookcompliance.co forwarder

cookcompliance.co is Cook Compliance's old domain; the website is cookcompliance.com (repo `davidavalerio/cookcompliance.com`). GitHub Pages serves cookcompliance.co from this repo, and every address on it, the home page and any other path, forwards to the cookcompliance.com home page, since that site is one page. Mail on cookcompliance.co is Google Workspace and is unaffected: its MX and SPF records at GoDaddy stay as they are.
